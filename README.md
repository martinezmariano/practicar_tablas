# Tablas con Juani

Aplicación web simple para practicar tablas de multiplicar.

## Cómo usarla

1. Descomprimir la carpeta.
2. Abrir `index.html` con Chrome, Edge, Safari o Firefox.
3. No necesita instalación ni servidor.

## Modos

- **Practicar:** las cuentas difíciles aparecen más seguido.
- **Desafío 1 minuto:** intenta superar el récord de respuestas correctas.
- **Progreso:** muestra qué operaciones están aprendidas, dudosas o difíciles.

## Cómo clasifica las cuentas

- **Aprendida:** al menos 4 intentos, 90% o más de precisión y buena cantidad de respuestas en 3 segundos o menos.
- **Dudosa:** 65% o más de precisión.
- **Difícil:** menos de 65%.
- **Sin practicar:** todavía no apareció.

El progreso se guarda automáticamente en el navegador mediante `localStorage`.
